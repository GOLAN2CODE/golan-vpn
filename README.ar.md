# جولان VPN

[English](README.md)

نسخة معاينة Android **1.0.1-rc3 / الرمز 4**، الحزمة `com.ibngolan.vpn`. الحد الأدنى Android 7/API 24؛ البناء باستخدام SDK 35 والاستهداف API 34. هذه لقطة منقحة من مصدر التطبيق الحالي واختباراته القائمة.

## الوظائف

- محركات وصفحات مستقلة لبروتوكولات WireGuard وOpenVPN UDP/TCP وOutline/Shadowsocks.
- استيراد إعدادات المستخدم وإدارة الأنفاق والخوادم وخانات الإعداد اليدوي للبروتوكولات.
- جلب الخوادم ومراجعتها وتشخيص الاتصال وعدادات المرور وتقسيم مرور التطبيقات وإدارة دورة الاتصال.
- موافقة VPN من Android وخدمة اتصال أمامية وموارد عربية وإنجليزية وهوية GOLAN.
- تخزين محلي آمن للإعدادات وكود نسخ احتياطي واستعادة. يلزم إعداد صالح وخادم يمكن الوصول إليه.

## التثبيت والاستخدام

ملف APK الموجود **نسخة تجريبية موقعة بمفتاح debug**، محفوظ دون تغيير. اسمح بالتثبيت للتطبيق الذي يفتح APK، ثم ثبّت وأضف إعداد اتصال صالحاً ووافق على نافذة VPN في Android. اختلاف توقيع النسخة يمنع التحديث المباشر؛ إزالة التطبيق تمحو إعداداته المحلية، لذا احتفظ بنسخة مصدّرة أولاً.

تدقيق مصادر وتراخيص المكتبات الأصلية غير مكتمل؛ ترد المعلومات المعروفة والأسئلة المتبقية في [THIRD_PARTY.md](THIRD_PARTY.md). تجهيز الملفات لا يثبت اعتماد الأمان للإنتاج أو توفر الخوادم الآن.

## المصدر الكامل والبناء

الأرشيف `golan-vpn-1.0.1-rc3-source.zip` معدّ للإرفاق بإصدار . نزّله وفك ضغطه قبل فتح المشروع أو بنائه؛ صفحة مستودع تعرض README فقط لا تحتوي مصدر التطبيق. يشمل الأرشيف الكود والاختبارات القائمة وGradle wrapper والموارد وJAR ومكتبة Outline الأصلية اللازمة للبناء. لا يشمل مفاتيح التوقيع أو مسار SDK الخاص بالمطور.

ثبّت JDK 17 وAndroid SDK 35، واضبط `ANDROID_HOME`/`ANDROID_SDK_ROOT` أو أنشئ `local.properties` محلياً مع `sdk.dir`، ثم شغّل من جذر الأرشيف:

```powershell
.\gradlew.bat :app:assembleDebug
```

في Linux/macOS استخدم `chmod +x gradlew && ./gradlew :app:assembleDebug`. ينزّل Gradle الاعتماديات المعلنة. يضع إعداد البناء الحالي النتائج في مجلد النظام المؤقت داخل `GolanVPN-build/<project-path-hash>/app/outputs/apk/debug/`. لم تُعد الاختبارات خلال التجهيز. مكتبة Outline المرفقة arm64 فقط؛ وجود معماريات أخرى في APK بسبب اعتماديات أخرى لا يثبت دعم Outline لها.

## الحدود والخصوصية

المحركات وكود الاستيراد موجودة، لكن لم يُجر اختبار اتصال جديد أو اعتماد جميع الأجهزة أو الأداء أو DNS/IPv6. قد تتغير كلمات مرور وعناوين الخوادم العامة. ظهور حالة الاتصال وحده لا يثبت إخفاء الهوية أو نجاح التوجيه أو منع كل تسريب. يطلب المصدر أذونات الشبكة والإنترنت، وتتصل وظائف جلب الخوادم وتشخيص IP بخدمات خارجية. راجع المزود والإعداد قبل الاستخدام.

استُبعدت إعدادات المستخدم والنسخ الاحتياطية وبيانات الجلب والسجلات واللقطات والمخرجات المؤقتة والأدلة التاريخية. احتُفظ بكود التطبيق واختباراته وسلوكه الشبكي. لم تُضف رخصة جديدة للكود الأصلي؛ راجع [LICENSE-STATUS.md](LICENSE-STATUS.md).
